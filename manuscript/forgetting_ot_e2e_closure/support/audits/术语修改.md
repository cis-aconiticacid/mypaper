# 术语修改建议

## 1. 删除 active-set contraction

全文删除 active-set contraction，不改写成另一个新的同类术语。

physical compaction 可以保留，作为具体执行动作的名称：问题通过释放检查后，从所有 per-problem batched state 中物理移除并压缩 batch。不得把 active-set contraction 写成与 physical compaction 并列的另一种机制。

Source：sections/1_introduction.tex；sections/3_method.tex。

## 2. 将 depth 全文改为 iteration number

全文不再使用 completion depth、completion depths、depth variation、depth profile、depth heterogeneity 等以 depth 表示迭代次数的说法，统一改为 iteration number(s) 或明确的 iteration-count 表述。

建议将每个问题的符号 \(\ell_t\) 改为不带 depth 含义的 \(n_t\)，并在首次出现处定义为：

> For problem \(t\), \(n_t\) is the batched-iteration number of the first configured verifier audit at which the problem passes.

所有相关公式、文字、图注、表注、实验描述和附录同步替换：

- completion depth \(\rightarrow\) iteration number;
- completion depths \(\rightarrow\) iteration numbers;
- \(\ell_t\rightarrow n_t\);
- \(\ell_{\max}\rightarrow n_{\max}\);
- depth-based \(\rightarrow\) iteration-number-based 或直接改写为自然语言。

Source：sections/0_abstract.tex；sections/1_introduction.tex；sections/2_setting_related.tex；sections/3_method.tex；sections/4_cost_and_hypothesis.tex；sections/5_experiments.tex；sections/6_scope.tex；sections/7_conclusion.tex；sections/A_appendix.tex。

## 3. 尽量将 audit 改为 check，并统一 verifier 名称

论文正文尽量将 audit 改为 check：在预先配置的 check interval 到达时，对当前问题执行一次 verifier check。check 是检查时点或检查动作，不是另一种迭代计数。

统一使用 two-marginal verifier 作为释放检查组件的名称。将 production audit 改为 production check，将 configured audit 改为 configured verifier check，将 audit interval 改为 check interval。删除或统一改写 two-sided stopping check、full check 等并列称呼。

建议将相关定义改为：

> Let \(n_t\) denote the batched-iteration number of the first configured verifier check at which problem \(t\) passes the two-marginal verifier.

随后使用：

> \(A_k=|\{t:n_t\ge k\}|\) is the number of problems still active before batched iteration \(k\).

同时明确 check interval 表示两次 verifier checks 之间的 batched iterations 数量。不得再把 \(n_t\) 写成 first production check 的编号或 check 次数。

Source：sections/3_method.tex；sections/4_cost_and_hypothesis.tex；sections/A_appendix.tex。

## 4. 删除 completion-depth profile 并改用自然描述

全文删除 completion-depth profile，不为 batch 内各问题的 iteration numbers 另起一个 profile 术语。

需要描述一个 batched window 中各问题所需的迭代次数时，直接使用：

> the iteration numbers required by the problems in the batched window

或：

> the numbers of iterations needed by the problems in the batched window

需要表达每次 batched iteration 前剩余多少问题时，保留 survival curve \(A_k\)，但不要再称其为 completion-depth profile。

Source：sections/1_introduction.tex；sections/4_cost_and_hypothesis.tex；改名.md。

## 5. 删除 depth-to-work，不提出替代术语

全文删除 depth-to-work，包括术语表、章节标题、贡献描述和正文中的该词。

本条暂不提出替代命名。相关公式是否保留以及应如何叙述，另行决定；不得将其改名为 exact work identities 或任何新的术语。

Source：sections/4_cost_and_hypothesis.tex；改名.md。

## 6. 删除 within-window completion disagreement

全文删除 within-window completion disagreement，不将其作为新的术语。

改用用户指定的自然语言：

> different number of iterations to complete the batch

该表述用于说明同一 batch 内的问题需要不同数量的 iterations 才能完成，不再为这一现象单独命名。

Source：sections/1_introduction.tex；sections/5_experiments.tex；改名.md。

## 7. 原文出现术语的改名建议

以下建议只要求在正文中使用普通描述，不把替代表述重新定义为新的论文术语；不直接修改论文正文或改名表。

### 直接改为普通描述

| 当前术语 | 建议改法 |
|---|---|
| updated-marginal screen | a preliminary check using the current marginals |
| shadow replay | replaying the screened results and checking each with the verifier |
| fixed-work grouping | groups with the same total iterations times |
| width-cost curve | runtime as a function of batch width |
| phase-active | the problems processed in each fixed phase |
| phase-boundary retirement | completed problems are removed only at phase boundaries |
| rebucketing | 不改 |
| projected-carry | initializing with the projected previous state |
| shared-anchor | using one initialization for multiple problems |
| paired-consumer-subtracted | paired comparison after subtracting consumer time |
| release-fair controls | controls using the same release rule |
| width-one | processing one problem at a time |
| backend-matched | comparison using the same backend |
| inner-backend | the backend used for the inner OT updates |
| row-sharded | partitioning the matrix by rows |
| coupling-to-consumer boundary | the boundary between the OT coupling and the downstream consumer |
| output-deviation diagnostic | checking differences in the outputs |
| proposal alignment | the relationship between the initialization and the convergence modes |
| weighted quotient | 不改|

### 删除原术语并直接叙述

以下词不保留为论文术语，直接使用普通句子：

| 当前术语 | 删除后的自然表述 |
|---|---|
| two-marginal stopping check | the verifier checks both the row and column residuals |

phase-active、phase-boundary retirement 和 release-fair controls 也不得保留为带连字符的标签；上表中的表达只能作为句子使用。

统一要求：论文正文、摘要、图注、表注、实验描述和附录中的 audit 尽量改为 check，并统一使用 verifier check、check interval 等直接表述。所有替代表述不得恢复 depth、active-set contraction、completion-depth profile 或 depth-to-work，也不得为了替换它们再创造新的复合术语。所有涉及 iteration numbers 的改动必须同步到正文、摘要、图注、表注、实验描述、附录和符号。
